## Project summary

The application is a PHP MVC ERP system for authentication, inventory, tracker installations, sales, purchases, accounting, requisitions, reports, notifications, suppliers, clients, permissions, and user administration. The root [README](../README.md) contains the quick-start overview, badges, current screenshots, configuration, API summary, and deployment essentials.
