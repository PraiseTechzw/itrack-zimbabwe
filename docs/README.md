# Documentation

This directory contains the project documentation for the iTrack Zimbabwe ERP application.

## Guides

- [Installation](INSTALLATION.md) – prerequisites, setup, and first run
- [Development](DEVELOPMENT.md) – workflow, coding conventions, and module structure
- [Architecture](ARCHITECTURE.md) – request flow, MVC layout, and core components
- [Deployment](DEPLOYMENT.md) – production deployment considerations
- [Security](SECURITY.md) – hardening and responsible disclosure guidance

## Project summary

The application is a PHP MVC ERP system for authentication, inventory, installations and deinstallations, sales, purchases, accounting, requisitions, reports, suppliers, clients, permissions, and user administration. The root [README](../README.md) contains the current setup, configuration, module, API, and deployment overview.
