# Security Guide

## General recommendations

- Keep the application and server dependencies updated.
- Restrict file permissions for [storage](../storage) and [uploads](../uploads).
- Validate all uploaded files in the server-side handlers.
- Use strong passwords and rotate credentials regularly.
- Avoid committing secrets, local credentials, or environment-specific values to the repository.

## Reporting a vulnerability

Please report security issues privately through the repository maintainer or a secure channel rather than opening a public issue.
